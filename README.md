E-Commerce Product Profitability & Recommendation Strategy

This repository contains my capstone project, completed after 200 hours of Data Analytics and Business Intelligence coursework.

The project explores how Power BI and Machine Learning can help analyse e-commerce product profitability and develop data-driven product recommendation strategies to improve cross-selling opportunities and business profit.

Tools & Technologies

Python, Pandas, NumPy, scikit-learn

Machine Learning: K-Means Clustering, PCA and Market Basket Analysis

Power BI, Power Query and DAX

Matplotlib and Seaborn

Collaboration Welcome

I welcome collaborators interested in improving the machine learning models, validating product recommendations and exploring ways to increase e-commerce profitability through data-driven insights.

Ideas, feedback and contributions are welcome!
